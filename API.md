# API библиотеки pykrcc

Документация относится к публичному API модуля `pykrcc/pykrcc.py`.
Пример импорта из корня репозитория:

```python
from pykrcc import pykrcc as krcc
```

## `Commu`

Класс соединения с контроллером Kawasaki.

```python
com = krcc.Commu("TCP as@192.168.0.2 23")
```

Создание объекта сразу открывает соединение и проходит процедуру входа.
Для TCP-строки подключения поддерживается формат:

```text
TCP [[login@]host] [port] [timeout_ms] [nodelay]
```

Например, `TCP as@192.168.0.2 9000 3000 1`. По умолчанию используются логин
`khidl`, хост `localhost`, порт `23`, тайм-аут установки соединения `10000` мс
и выключенный `TCP_NODELAY`.

Экспериментальная строка последовательного порта: `COM1 [baud]`; скорость
по умолчанию — 9600. Для POSIX также принимаются имена устройств `/dev/...` и
`tty...`.

Конструктор может выбросить:

- `ConnectError` — не удалось установить TCP-соединение;
- `LoginError` — не удалось выполнить вход;
- `NoResponseError` — нет ответа на проверочную команду;
- `CommuError` — некорректная строка подключения или другая ошибка библиотеки.

Объект поддерживает менеджер контекста: при выходе из `with` вызывается
`dispose()`.

### Свойства и атрибуты

| Имя Python | Имя совместимости | Описание |
|---|---|---|
| `is_connected` | `IsConnected` | `True`, пока соединение открыто |
| `timeout_value` | `TimeoutValue` | Тайм-аут операций `save`/`load` в мс; по умолчанию 5000 |
| `load_save_msg` | `LoadSaveMsg` | Сообщения контроллера из последней операции `save`/`load`, кроме обработанных вопросов |
| `as_inquiry` | `asInquiry` | Callback для вопросов во время `save`/`load` |
| `cmd_inquiry` | `cmdInquiry` | Callback для строк ответа на обычные команды |
| `progress` | — | Callback прогресса передачи `save`/`load` |
| `load_save_output` | — | Callback для каждой текстовой строки контроллера во время `save`/`load` |

Callbacks изначально равны `None`. Значения свойств `TimeoutValue` и
`timeout_value` взаимозаменяемы.

### Методы

#### `command(cmd=None, tmo=None) -> [code, text]`

Отправляет команду AS и возвращает код результата и текст ответа.

- `command()` ничего не отправляет, а считывает уже принятые сообщения.
- `command("where")` использует тайм-аут 500 мс.
- `command("where", 3000)` задаёт время ожидания в миллисекундах.
- Отрицательный тайм-аут означает ожидание до 60 секунд.

Коды результата:

| Код | Значение |
|---:|---|
| `0` | Ответ получен, контроллер вернул приглашение `>` |
| `-1` | Тайм-аут без ответа |
| `-2` | Получен неполный ответ, например контроллер ожидает ввода; также возвращается при транспортной ошибке |

Если назначен `cmd_inquiry`, строки ответа передаются callback-у и не добавляются
в `text`.

#### `save(fname, prog="", qual="") -> int`

Сохраняет содержимое контроллера в локальный файл `fname`.

- `save("backup.as")` — всё содержимое;
- `save("programs.as", "pg1,pg2")` — выбранные программы;
- `save("program.as", "pg1", "/P")` — программа с квалификатором;
- `save("backup.as", "/P")` — краткая форма передачи квалификатора.

Возможные результаты общие с `load`: `0` при нормальном завершении, `-1` при
тайм-ауте/ошибке передачи, `-2` при ошибке команды контроллера, `-3` при ошибке
локального файла, положительное число — число вопросов контроллера, на которые
был дан ответ. Сообщения контроллера доступны через `load_save_msg`.

#### `load(fname, qual="") -> int`

Загружает локальный файл `fname` в контроллер. `qual` — строка квалификатора,
например `"/Q"`. Библиотека проверяет, что локальный файл существует, перед
отправкой команды контроллеру.

Возвращаемые значения: `0` — успешно; `-1` — тайм-аут или ошибка передачи;
`-2` — контроллер не принял команду; `-3` — пустое имя или локальный файл
недоступен; положительное число — количество обработанных вопросов.

#### `connect(port) -> int`

Закрывает предыдущее соединение и пытается подключиться по новой строке порта.
Возвращает `0` при успехе, `-1` при ошибке соединения и `-2` при ошибке входа.

#### `disconnect() -> bool`

Закрывает соединение. Возвращает `True` при успешном закрытии.

#### `dispose() -> None`

Закрывает соединение и останавливает журнал. Имеет синоним `Dispose()`.
Вызывается автоматически при выходе из менеджера контекста.

#### `name() -> str`

Возвращает строку порта, переданную конструктору или последнему `connect()`.

#### `start_log(log_fname) -> bool`

Начинает записывать принимаемые данные в файл журнала. Перед запуском нового
журнала прежний закрывается. Возвращает `False`, если файл открыть не удалось.
Синоним: `startLog()`.

#### `stop_log() -> bool`

Останавливает запись журнала. Синоним: `stopLog()`.

## Callbacks

### `ASInquiry(msg: str) -> Optional[str]`

Вызывается при вопросах контроллера во время `save`/`load`. Верните строку,
которую нужно отправить контроллеру (например, `"0\n"`). Возврат `None`
позволяет библиотеке подобрать ответ из `DEFAULT_RESPONSES`.

### `LoadSaveOutput(msg: str) -> None`

Вызывается для каждой текстовой строки контроллера во время `save`/`load`,
включая строки-вопросы до вызова `ASInquiry`. Установите `com.load_save_output`,
чтобы отображать ход операции по мере получения сообщений.

### `CmdInquiry(msg: str) -> Optional[str]`

Вызывается для каждой строки ответа на `command()`. Возвращённая непустая строка
отправляется контроллеру. При установленном callback-е обычный текст ответа не
накапливается в возвращаемом значении `command()`.

### `Progress(done: int, total: int) -> None`

Сообщает ход передачи. `done` — число переданных байт; значение `-1` означает
завершение. Для `save` размер `total` равен `-1`; при `load` он отражает размер
локального файла, когда известен.

Пример:

```python
def show_progress(done, total):
    if done < 0:
        print("Передача завершена")
    else:
        print("%s / %s" % (done, total))

with krcc.Commu("TCP 192.168.0.2") as com:
    com.progress = show_progress
    result = com.save("backup.as")
```

## Имена совместимости

Класс доступен также как `Ccommu`. Члены из API .NET имеют Python-синонимы:

```python
com.IsConnected == com.is_connected
com.TimeoutValue = com.timeout_value = 3000
com.LoadSaveMsg == com.load_save_msg
com.asInquiry = com.as_inquiry
com.cmdInquiry = com.cmd_inquiry
com.startLog("controller.log")
com.stopLog()
com.Dispose()
```

## Исключения и константы модуля

- `CommuError` — базовое исключение; свойство `Message` возвращает тот же текст,
  что и `str(error)`.
- `ConnectError`, `LoginError` и `NoResponseError` — специализированные ошибки
  установления соединения.
- `DEFAULT_RESPONSES` — пары «образец сообщения контроллера, ответ», используемые
  как запасная обработка вопросов при `save`/`load`.
- `DEBUG` — при значении `True` печатает отладочную информацию протокола в `stderr`.
