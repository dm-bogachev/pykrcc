# pykrcc — связь с контроллерами Kawasaki AS

`pykrcc` — реализация API `KRcc.Commu` на Python для обмена данными с контроллерами
роботов Kawasaki. Используются только модули стандартной библиотеки: DLL,
.NET/pythonnet и pyserial не требуются. Код рассчитан на Python 3.8+ и Windows,
Linux и macOS.

Реализованы TCP-соединение, отправка AS-команд, операции передачи программ
`SAVE`/`LOAD`, журнал связи и экспериментальная поддержка последовательного порта.
Протокол восстановлен по `krcc64.dll` и проверен на имитации контроллера, но не
на реальном роботе.

## Установка и импорт

Скачайте или клонируйте репозиторий. Запускайте команды из корня проекта.
В модуле `pykrcc/pykrcc.py` находится реализация библиотеки:

```python
from pykrcc import pykrcc as krcc

with krcc.Commu("TCP 192.168.0.2") as com:
    code, response = com.command("where", 3000)
    print(code, response)
```

Для TCP можно указать логин, адрес, порт, тайм-аут установки соединения и
`TCP_NODELAY`: `TCP as@192.168.0.2 23 10000 1`. По умолчанию используются логин
`khidl`, порт `23` и тайм-аут подключения `10000` мс.

Подробное описание классов, функций, свойств, делегатов и кодов возврата:
[API pykrcc](API.md).

## Консольный терминал

Запустите интерактивный терминал из корня репозитория:

```console
python terminal.py
```

Без аргументов программа запросит тип соединения и параметры TCP или COM.
Можно передать строку подключения напрямую:

```console
python terminal.py "TCP as@192.168.0.2 23"
python terminal.py "COM1"
python terminal.py --timeout 1500 "TCP 192.168.0.2 23"
```

Обычная строка в приглашении `AS>` отправляется контроллеру как команда AS.
Ручные команды `SAVE` и `LOAD` заблокированы; используйте локальные команды:

| Команда | Действие |
|---|---|
| `!save <файл> [программы] [/P/R/L..]` | Сохранить данные контроллера в локальный файл; список программ и квалификаторы необязательны |
| `!load <файл> [/Q]` | Передать локальный файл контроллеру |
| `!log <файл>` | Записывать сообщения связи в файл |
| `!log off` | Остановить запись журнала |
| `!tmo <мс>` | Изменить ожидание ответа на AS-команду |
| `!help` | Показать справку |
| `!quit` | Отключиться и выйти |

Например, `!save backup.as /P` сохраняет данные в `backup.as` с квалификатором
`/P`, а `!load program.as /Q` загружает локальный файл. Пробелы в аргументах
локальных команд в консольном терминале не поддерживаются.

Аргумент `--timeout` задаёт тайм-аут команды в миллисекундах (по умолчанию
1000 мс). Флаг `--no-progress` отключает вывод хода передачи `SAVE`/`LOAD`.

## Графический терминал

Запустите GUI:

```console
python terminal_gui.py
python terminal_gui.py "TCP as@192.168.0.2 23"
```

GUI написан на `tkinter` из стандартной библиотеки Python, сторонние GUI-зависимости
не нужны. Если в установленной сборке Python отсутствует `tkinter`, потребуется
установить вариант Python, содержащий Tk.

В одном окне собраны:

- параметры TCP/COM-соединения, тайм-аут и кнопки подключения/отключения;
- AS-терминал с отправкой команд и выводом сообщений контроллера;
- форма `SAVE`: выбор локального файла кнопкой «Обзор…», список программ,
  квалификаторы и кнопка сохранения;
- форма `LOAD`: выбор существующего локального файла, квалификатор и кнопка загрузки;
- настройка файла журнала и кнопки включения/выключения записи;
- индикатор прогресса передачи.

`SAVE` передаёт данные контроллера в выбранный локальный файл; `LOAD` отправляет
выбранный локальный файл контроллеру. В поле терминала доступны локальные команды
`!save`, `!load`, `!log`, `!tmo`, `!help` и `!quit`, как и в консольной версии.

## Ограничения

- Реальное поведение зависит от модели и настроек контроллера. Проверка на
  имитации не заменяет тестирование на целевом оборудовании.
- COM-транспорт экспериментальный, проверен только по документации ОС и не
  проверен на оборудовании. Работу команд и передачи файлов по COM следует
  проверять на целевом контроллере.
- `asInquiry` обрабатывает вопросы `SAVE`/`LOAD`; если callback вернёт `None`,
  библиотека попробует встроенные ответы `DEFAULT_RESPONSES`.
- Классы `Robot`, `Joint` и `Trans` в проект не входят.
- По умолчанию текст на проводе обрабатывается как `latin-1`. Перевод строки
  файлов `SAVE` соответствует платформе; его можно задать через `Commu.newline`.
